📋 Güncellenen Form Verileri - Satır Bazlı Raf Kodları

🔄 Yapılan Değişiklikler

✅ Yeni Özellikler:

  • Satır Bazlı Raf Kodları: Her satırda farklı raf kodu olabilir
  • Miktar Kaldırıldı: Seri numarası olduğu için her zaman 1
  • 3 Sütunlu Tablo: Seri | Stok | Raf

📊 Tablo Yapısı

Seri Stok Raf
SN123456 PRD001 RAF-A01
SN789012 PRD002 RAF-B05
SN345678 PRD001 RAF-C12

📤 Gönderilecek Form Alanları

  • sayimID Hidden - Sayım oturumu ID'si
  • shelfCode Hidden - Varsayılan raf kodu
  • rowCount Hidden - Toplam satır sayısı
  • sayimData Hidden - JSON formatında tüm veriler
  • product_codes Hidden - Virgülle ayrılmış stok kodları
  • serial_nos Hidden - Virgülle ayrılmış seri numaraları
  • shelf_codes Hidden - Virgülle ayrılmış raf kodları

📊 JSON Veri Formatı (sayimData)

[ { "product_code_2": "PRD001", "serial_no": "SN123456", "shelfCode": "RAF-A01", "miktar": "1" }, { "product_code_2": "PRD002", "serial_no": "SN789012", "shelfCode": "RAF-B05", "miktar": "1" }, { "product_code_2": "PRD001", "serial_no": "SN345678", "shelfCode": "RAF-C12", "miktar": "1" } ]

📝 Ayrı Alan Formatı

product_codes: "PRD001,PRD002,PRD001" serial_nos: "SN123456,SN789012,SN345678" shelf_codes: "RAF-A01,RAF-B05,RAF-C12" shelfCode: "RAF-A01" (varsayılan) sayimID: "SAY2024001" rowCount: "3"

🔧 Backend'de Kullanım

JSON Formatı ile:

var sayimData = JSON.parse(form.sayimData); for(var i=0; i<sayimData.length; i++) { var item = sayimData[i]; var productCode = item.product_code_2; var serialNo = item.serial_no; var shelfCode = item.shelfCode; var miktar = item.miktar; // Her zaman "1" // Veritabanına kaydet }

Ayrı Alanlar ile:

var productCodes = form.product_codes.split(','); var serialNos = form.serial_nos.split(','); var shelfCodes = form.shelf_codes.split(','); for(var i=0; i<productCodes.length; i++) { var productCode = productCodes[i]; var serialNo = serialNos[i]; var shelfCode = shelfCodes[i]; var miktar = 1; // Her zaman 1 // Veritabanına kaydet }

💡 Önemli Notlar

  • Satır Bazlı Raf: Her ürün farklı rafta olabilir
  • Seri Numarası: Her ürün benzersiz seri numarasına sahip
  • Miktar Sabit: Seri numarası olduğu için her zaman 1
  • Esnek Yapı: Hem JSON hem ayrı alanlar mevcut

🎯 Kullanım Senaryosu

  1. Ürün Tarama: Seri numarası barkodu taranır
  2. Ürün Bilgisi: Stok kodu ve raf bilgisi otomatik gelir
  3. Tabloya Ekleme: Seri-Stok-Raf olarak listelenir
  4. Farklı Raflar: Her ürün farklı rafta olabilir
  5. Kaydetme: Tüm satırlar toplu olarak kaydedilir

✅ Avantajlar

  • Gerçekçi Senaryo: Ürünler farklı raflarda olabilir
  • Seri Takibi: Her ürün benzersiz şekilde takip edilir
  • Basit Miktar: Seri numarası = 1 adet
  • Esnek Veri: Backend için iki farklı format
