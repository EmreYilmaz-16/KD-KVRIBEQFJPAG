📋 Form Verileri - Backend'e Gönderilecek Veriler

🎯 İstenen Veri Yapısı

Satır Verileri: product_code_2, serial_no, shelfCode

Belge Verisi: sayimID

📤 Gönderilecek Form Alanları

  • sayimID Hidden - Sayım oturumu ID'si
  • shelfCode Hidden - Aktif raf kodu
  • rowCount Hidden - Toplam ürün sayısı
  • sayimData Hidden - JSON formatında tüm veriler
  • product_codes Hidden - Virgülle ayrılmış ürün kodları
  • serial_nos Hidden - Virgülle ayrılmış seri numaraları
  • quantities Hidden - Virgülle ayrılmış miktarlar

📊 JSON Veri Formatı (sayimData)

[ { "product_code_2": "PRD001", "serial_no": "123456", "shelfCode": "RAF-A01", "miktar": "5" }, { "product_code_2": "PRD002", "serial_no": "789012", "shelfCode": "RAF-A01", "miktar": "3" } ]

📝 Ayrı Alan Formatı

product_codes: "PRD001,PRD002,PRD003" serial_nos: "123456,789012,345678" quantities: "5,3,2" shelfCode: "RAF-A01" sayimID: "SAY2024001"

🔧 Backend'de Kullanım

JSON Formatı ile:

var sayimData = JSON.parse(form.sayimData); for(var i=0; i<sayimData.length; i++) { var item = sayimData[i]; // item.product_code_2 // item.serial_no // item.shelfCode // item.miktar }

Ayrı Alanlar ile:

var productCodes = form.product_codes.split(','); var serialNos = form.serial_nos.split(','); var quantities = form.quantities.split(','); for(var i=0; i<productCodes.length; i++) { var productCode = productCodes[i]; var serialNo = serialNos[i]; var quantity = quantities[i]; var shelfCode = form.shelfCode; }

✅ Avantajlar

  • İki Format: Hem JSON hem ayrı alanlar
  • Esneklik: Backend'de hangi format uygunsa o kullanılabilir
  • Güvenlik: Tüm veriler gizli alanlarda
  • Bütünlük: Tüm gerekli veriler mevcut

🚀 Form Gönderim Akışı

  1. Kullanıcı Kaydet Butonuna Basar
  2. confirmSave() çalışır - Doğrulama yapar
  3. prepareSaveData() çalışır - Verileri toplar
  4. Gizli alanlar doldurulur - Hem JSON hem ayrı alanlar
  5. Form submit edilir - Backend'e gönderilir
